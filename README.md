# 토끼 로봇 (Raspberry Pi Pico W)

얼굴을 돌리는 서보 1개, 귀를 움직이는 서보 2개, LED 매트릭스 눈 2개로 이루어진 토끼 로봇의 테스트 펌웨어와 조작판입니다.
Pico를 USB 케이블로 컴퓨터에 연결하고, 브라우저 조작판에서 움직임 테스트와 버그 테스트를 합니다.

| 파일 | 놓는 곳 | 역할 |
|---|---|---|
| `pico/main.py` | Pico W | 서보 3개와 눈 2개를 구동하고, USB로 명령을 주고받는 펌웨어 (MicroPython) |
| `panel.html` | 컴퓨터 | 크롬/엣지에서 여는 조작판 (Web Serial) |
| `docs/wiring.html` | 컴퓨터 | 배선도와 핀 연결표, 전원 점검 목록 |

## 부품

- Raspberry Pi Pico W (MicroPython)
- 서보: 얼굴 MG996 1개, 귀 MG90S 2개 (PCA9685 없이 Pico 핀에 직접 연결)
- 눈: MAX7219 8×8 LED 도트 매트릭스 2개 (데이지체인)
- 전원: 5V 6A 어댑터 + DC 잭 터미널, 미니 브레드보드
- KMG 16V 전해 콘덴서 (서보 전원 줄 안정화)

## 배선 요약

괄호 안은 Pico 물리 핀 번호입니다. 자세한 그림은 `docs/wiring.html`을 브라우저로 여세요.

| 연결 | Pico 핀 |
|---|---|
| 얼굴 서보 신호 (주황) | GP12 (16) |
| 왼쪽 귀 서보 신호 (주황) | GP11 (15) |
| 오른쪽 귀 서보 신호 (주황) | GP10 (14) |
| 서보 빨강 3개, 어댑터 +, 콘덴서 긴 다리 | 브레드보드 + 줄 (Pico에 연결하지 않음) |
| 서보 갈색 3개, 어댑터 −, 콘덴서 흰 띠 쪽 다리 | 브레드보드 − 줄 |
| 공통 GND: − 줄 | GND (38) |
| 눈 VCC / GND | VBUS (40) / GND (28) |
| 눈 DIN / CLK / CS | GP19 (25) / GP18 (24) / GP17 (22) |

- Pico GND(38)와 − 줄은 꼭 연결합니다. 없으면 서보가 떨리거나 움직이지 않습니다.
- 콘덴서는 방향이 있습니다. 반대로 꽂으면 부풀거나 터질 수 있습니다.
- 어댑터 5V는 Pico 핀에 연결하지 않습니다. Pico 핀은 3.3V 전용입니다.

## 사용법

1. Pico W에 MicroPython 펌웨어를 올립니다.
2. Thonny로 `pico/main.py`를 Pico에 **`main.py`라는 이름으로** 저장한 뒤, **Thonny를 닫습니다** (USB 포트를 놓아 줘야 조작판이 연결됩니다).
3. 컴퓨터의 **크롬이나 엣지**에서 `panel.html`을 엽니다. 사파리, 파이어폭스, 휴대폰 브라우저는 USB 시리얼을 지원하지 않습니다.
4. **[Pico 연결]** 을 누르고 Pico를 고릅니다. 다음부터는 열면 자동으로 연결됩니다.
5. 서보 어댑터 전원을 켜고 **[셀프 테스트]** 를 실행합니다.

처음에는 서보 혼을 빼 둔 상태로 셀프 테스트를 돌리고, 각도를 확인한 뒤 기구에 다는 것을 권장합니다.

## 조작판 기능

- **서보 직접 조작:** 슬라이더, ±1°/±5° 미세 조정, 중앙·최소·최대 / 내림·세움 바로가기, 힘 빼기(비상 정지)
- **동작 실행:** 반응 동작, 고개 좌우, 귀 쫑긋, 귀 번갈아, 눈 깜빡, 전체 범위 왕복, 셀프 테스트, 전원 강하 테스트
- **반복 테스트:** 동작·횟수·간격을 정해 연속 실행 (진행률 표시)
- **눈:** 표정 7종, 8×8 도트 직접 그려 보내기, 밝기, 좌우 바꾸기, 180° 회전, 자동 깜빡임
- **보정:** 서보를 원하는 위치로 옮긴 뒤 "현재 위치로"를 눌러 각도 저장, [Pico에 저장]으로 `config.json`에 기록
- **진단:** 가동 시간, 제어 루프 속도·최대 지연, 남은 메모리, 부팅 원인, 로그(파일 저장 가능). Pico의 오류 메시지(Traceback)도 로그에 그대로 표시

## Thonny 셸에서 쓰기

조작판 없이 Thonny 셸에서도 조작할 수 있습니다. `h`를 입력하면 명령어 목록이 나옵니다.

```
f 120          얼굴 120°           l / r <각도>   왼쪽 / 오른쪽 귀
up / down      귀 세우기 / 내리기   c              기본 자세
e smile        눈 표정             a alert 30     반응 동작 30회 반복
x              동작 정지           relax          힘 빼기
s              상태                save           설정 저장
```

## 통신 형식

USB 시리얼로 한 줄에 하나씩 주고받습니다.

- 컴퓨터 → Pico: JSON 명령. 예) `{"c": "servo", "id": "face", "deg": 120}`
- Pico → 컴퓨터 (조작판이 `{"c": "hello"}`를 보낸 뒤부터)
  - `@C` 설정과 표정·동작 목록
  - `@S` 상태 (약 0.15초마다)
  - `@L` 로그
  - `@R` 명령 결과 (명령 순서대로 하나씩)

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| [Pico 연결]을 눌러도 안 됨 | Thonny가 켜져 있으면 닫기, 크롬/엣지인지 확인 |
| "Pico에서 응답이 없습니다" | 진단의 [Pico 프로그램 다시 시작] 누르기, `main.py` 이름으로 저장했는지 확인 |
| 서보가 떨리거나 안 움직임 | Pico GND(38) ↔ − 줄 연결, 어댑터 전원 확인 |
| 서보가 움직일 때 Pico가 재부팅됨 | 콘덴서 방향·위치 확인, 어댑터 선을 굵게, 더 큰 용량 콘덴서 |
| 눈이 안 켜지거나 깨짐 | 배선 확인. MAX7219는 5V 칩이라 3.3V 신호를 못 알아들으면 레벨 시프터 필요 |
| 눈 좌우가 바뀜 / 거꾸로 보임 | 조작판의 [좌우 바꾸기] / [180° 회전] |
